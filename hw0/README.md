# DATA203 Homework 0: String Manipulation in Python

## Overview
This homework introduces foundational Python programming concepts with a focus on **string manipulation** and **text processing**. You'll work with real-world text data—specifically a biographical passage about jazz saxophonist Hank Mobley—to explore core string methods and sequence operations in Python.

## Learning Objectives
- Familiarize yourself with **Markdown** and **JupyterLab** environments
- Practice **basic Git and GitHub** workflows (forking, creating repositories)
- Use the **Linux terminal** in JupyterHub to perform file operations
- Master essential **Python string methods**:
  - `lower()`, `split()`, `replace()`, `count()`
- Apply string operations to analyze text content
- Understand how sequences (like lists) can be used to process text

## Key Tasks & Deliverables
1. **Markdown & Jupyter Lab Exploration**  
2. **GitHub Setup**  
3. **Linux Terminal Commands**  
4. **String Manipulation Exercises**
